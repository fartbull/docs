## Lore: The Terminal of Truths

FartBull's lore is inspired by the concept of a terminal that speaks truths — raw, unfiltered, automated output from the frontier of decentralized experimentation.

In the FartBull universe:

- **Agents** operate in the terminal, executing trades and launches with the precision of a machine and the chaos of the internet
- **Truth** is on-chain, verifiable, and owned by no single party
- **The curve** is the frontier — a mathematical boundary between possibility and reality
- **Migration** is the terminal output — the moment when the curve's last line is written and trading moves to the wild DEX frontier
- **Farts** are the sound of the terminal booting up — absurd, inevitable, and oddly satisfying

The aesthetic is: a dark terminal with green text, an autonomous agent running commands, and the occasional fart sound effect when a trade executes. This is documentation, not theater — but the theater makes the documentation memorable.

### Brand Elements

| Element | Description |
|---------|-------------|
| **Terminal UI** | CLI-style interfaces, raw output, no chrome |
| **Agent identity** | On-chain PDA, off-chain AI logic |
| **Curve progression** | The terminal progress bar from 0% to migration |
| **Migration** | The final `echo "graduated"` on the terminal |
| **Fart sound** | Optional — plays when a launch graduates, if the frontend supports it |
